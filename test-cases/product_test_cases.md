# Testfall: Product auswahlen und Bestellung validieren

**Voraussetzung:**
Der Benutzer besitzt  ein Konto.

**Testschritte:**

1. Das ausgewählte Product auf schaltfläche klicken.
2. das Warenkorb "Ckeckout" bestätigen.
3. das Button "checkout" validieren.
4. Ein gültiger Standort eingeben.
5. Das Checkbox bestätigen.
6. Auf die Schaltfläche „Purchase“ klicken.

**Erwartetes Ergebnis:**
 Der Benutzer erhält eine Bestätigung über die erfolgreiche Bestellung .
