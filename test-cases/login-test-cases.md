# Testfall: Registrierung mit gültigen Daten

**Voraussetzung:**
Der Benutzer besitzt noch kein Konto.

**Testschritte:**

1. Die Registrierungsseite öffnen.
2. Einen gültigen Benutzernamen eingeben.
3. Eine gültige E-Mail-Adresse eingeben.
4. Ein gültiges Passwort eingeben.
5. Das Passwort bestätigen.
6. Auf die Schaltfläche „Registrieren“ klicken.

**Erwartetes Ergebnis:**
Das Benutzerkonto wird erfolgreich erstellt. Der Benutzer erhält eine Bestätigung über die erfolgreiche Registrierung und wird gegebenenfalls zur Login-Seite oder zum Dashboard weitergeleitet.


# Testfall: Login mit gültigen Zugangsdaten

**Voraussetzung:**
Der Benutzer besitzt ein registriertes Benutzerkonto.

**Testschritte:**

1. Die Login-Seite öffnen.
2. Einen gültigen Benutzernamen eingeben.
3. Ein gültiges Passwort eingeben.
4. Auf die Schaltfläche „Login“ klicken.

**Erwartetes Ergebnis:**
Der Benutzer wird erfolgreich zum Dashboard weitergeleitet.
